# PickData Copilot

PickData Copilot 是面向大数据时代的通用型数据 Agent。它把自然语言问数、指标分析、异常检测与波动归因串成一条可执行的智能分析链路，让用户不必先掌握 SQL、数仓表结构或指标口径，就能从数据中获得可信结论。

与只负责生成 SQL 的方案不同，PickData Copilot 会把意图识别、指标检索、槽位补全、SQL 编译与安全校验、查询执行、结果分析和归因过程完整写入 Trace。每一次回答都能被查看、回放和追溯，并支持在异常中断后继续执行。

## 核心能力

- **自然语言问数**：将业务问题转换为可执行的指标查询。
- **指标语义层**：统一指标口径、维度、时间范围和聚合逻辑，避免“同名不同义”。
- **安全查询**：通过 SQL AST 校验限制表、语句和访问范围，不把数据库控制权直接交给模型。
- **异常检测与归因**：对比当前窗口与历史基期，定位异常并计算主要影响维度。
- **全链路可观测**：记录 Agent 的每一次模型调用、工具调用、状态迁移和中间产物。
- **可插拔基础设施**：通过 Port 与 Adapter 隔离模型、数据库、缓存、向量库和消息队列。

## 适用范围

PickData Copilot 的架构不绑定具体行业，可服务于经营分析、销售分析、供应链分析、运营监控、财务分析和研发效能等场景。首个演示使用物流拣运样例数据，仅用于验证完整的问数与归因闭环，不代表产品的能力边界。

## 设计原则

项目以事件流作为事实来源，所有任务状态和执行轨迹都由事件回放生成；Agent Runtime 采用有限状态机与工具循环，并通过 Skills 渐进加载领域知识。业务能力与中间件实现保持解耦，便于替换模型和数据源。

## 本地中间件

MySQL、Redis、Milvus 与 RocketMQ 可通过 [Docker Compose](deploy/README.md) 启动。
